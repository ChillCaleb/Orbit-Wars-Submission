# Project Docs

- `RL_LAB.md`: tactical lab workflow, recorded features, and training labels.
- `GENERAL_MODEL_TRAINING_ROADMAP.md`: general step-by-step map for starting training projects and knowing which deeper guide is needed.
- `HULL_TACTICAL_MARKET_METHOD.md`: standalone algorithmic automation method from the Hull market writeup, including risk controls and Python command shapes.
- `SELF_PLAY_TRAINING_METHOD.md`: self-play reinforcement learning method, commands, metrics, and next steps.
- `CPP_SELF_PLAY_LOCAL_RUN.md`: optional C++ simulator/rollout backend plan and local run commands.
- `KAGGLE_RESOURCES.md`: Kaggle replay datasets, public notebook ideas, and integration recommendations.

Generated run reports stay under `data/` next to their artifacts. Kaggle kernel bundles live under `kaggle/bundles/`, while source/reference notebooks live under `notebooks/`. The root `README.md` stays focused on copyable terminal commands.
